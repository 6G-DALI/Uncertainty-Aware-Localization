# Uncertainty-Aware-Localization
This repository contains the main experiment scripts used in the paper "SLA-Aware Conformal Uncertainty for Trustworthy CSI Localization in 6G". The script "Trustworthy_Localization_Experiments_full_modular.py" supports execution of the individual experiment workflows (Adaptive SCP, CQR, pooled and per-scenario experiments) in a modular file.
